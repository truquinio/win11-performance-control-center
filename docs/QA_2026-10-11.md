# Win11 Performance Control Center — QA of modular refactor

Scope: only the Win11 Control repo. No GitHub push, user configuration changes, browser termination, history deletion, or real WRITE executions.

## Source changes
- Reused existing C# ActionCatalog (89 allowlisted actions, 49 parameter definitions). No new catalog or duplicate module.
- Extracted shared formatting + result-table DOM primitives and the 63 KiB contextual action-results renderer to TypeScript components. Injected live catalog and dispatcher so module actions still call the original IPC provider. `src/Frontend/app.ts` reduced from approximately 2,855 to approximately 1,109 lines.
- Moved 204 lines of Storage / Cleanup / Hibernation ActionExecutor methods into `src/App/Core/ActionExecutor.Storage.cs`, preserving the dispatch boundary and service methods.
- Updated `scripts/action-certification.mjs` to trace authored interactive follow-ups across TypeScript modules; deliberately exclude generated catalog to avoid false route coverage.
- Added a frontend contract preventing accidental re-inlining of the action results monolith.
- Added a QA-only minimized WPF process profiler; stops only the process it launched.

## Remaining blockers for a fully certified final release
- Test real WRITE/UAC/denial/cancel/restart/recovery and rollback in a disposable, explicitly authorized Windows VM, with snapshots and no interference with the active workstation. Do not infer safety from DEMO/contract unit tests.
- Obtain the current approved Developer visual reference and close actual visual differences; tracked Developer image in docs/screenshots is obsolete. Then test DPI 100/125/150/200, NVDA/high contrast, and multimonitor.
- Measure full WPF+WebView2 memory/CPU/handles and repeated startup/interaction timing under real usage; one short parent-only sample cannot validate a performance target.
- Recycle Bin cleanup still requires manual restore; don't promise automatic rollback.

Current user instruction: do not publish interim builds or call this 100% complete. Preserve coordination notice `docs/COORDINATION_NOTICE_STORAGE_20261010.md` without adding/deleting it. Preserve conversation history and all unrelated project content.
